Reports are signed with the key whose fingerprint is 8DC1CCF8C3052039. Compare it, so a forged report signed with someone else's key is caught.

What this is not

It is an evidence aid, not a certification. It does not guarantee FDA, EU or DoD acceptance, and it is not legal or regulatory advice. The completeness check follows the NTIA 2021 minimum elements; the CISA 2025 additions shown are from a draft, so confirm them against CISA's current publication. Vulnerability data comes from the public OSV.dev database and can miss issues, especially in firmware or vendored code without a package URL.
